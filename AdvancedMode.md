# QGroundControl Advanced Mode

Custom QGroundControl builds start in **Regular Mode**. Advanced Mode exposes additional QGroundControl features and setup options.

## Enter Advanced Mode

1. Start the custom QGroundControl build.
2. Go to the **Application Settings** / main menu area.
3. Hold **Shift**.
4. While holding **Shift**, click the **Custom-QGroundControl Daily Version** text showing the application version.
5. QGroundControl will ask whether you want to enter **Advanced Mode**.
6. Confirm the prompt.

QGroundControl is now running in **Advanced Mode**.

## Return to Regular Mode

To leave Advanced Mode:

1. Hold **Shift**.
2. While holding **Shift**, click the **Custom-QGroundControl Daily Version** text again.
3. Confirm the prompt to leave Advanced Mode.

QGroundControl will return to **Regular Mode**.

> **Note:** This procedure is specific to this custom QGroundControl build. The standard QGC documentation may describe a different way of accessing Advanced Mode.
